# Dataset provenance

The original images and annotations belong to the Penn-Fudan Pedestrian
Database. Obtain them from the
[official database page](https://www.cis.upenn.edu/~jshi/ped_html/). Its readme
retains copyright with the relevant holders and asks users to observe the
applicable copying/reposting terms. This handoff supplies verification hashes
and derived coordinate facts instead of redistributing dataset photos, masks
or original annotation documents.

Citation: Liming Wang, Jianbo Shi, Gang Song and I-fan Shen,
*Object Detection Combining Recognition and Segmentation*, ACCV 2007.

Four evaluated annotations were deliberately changed in local copied examples.
The replacement files under `generated_annotations/` were produced by this
project's annotation serializer from object-coordinate facts. They are not
claimed to be naturally occurring annotation errors. The original dataset files
are unchanged. `manifest.json` identifies these cases, their original source
hashes, and the exact replacement hashes.

The eleven included labels came from the project owner reviewing red-box
overlays without seeing model predictions. There was one reviewer, with
clarification about rule scope for two cases. Guided practice case 01 is excluded.
Review history is retained; these are not labels generated by a coding model or
a multi-reviewer adjudication study.

All current comparison images are development data now. A future blinded test
set must exclude prior source images by SHA-256, not merely by filename or
annotation revision. `prior_image_exclusions.json` lists source images already
used in these experiments, the earlier smoke run and the integration benchmark.
Do not let a prompt-development assistant inspect future held-out labels or use
those labels in model requests.
