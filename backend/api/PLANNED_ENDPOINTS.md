## Shared conventions

- Paths include `/api/v1`; apply the backend origin or development proxy once.
- Required fields, nullability and defaults are in the schema appendix. Null does not imply optional.
- Multipart binary fields are File/Blob values in FormData. Marker strings below are placeholders; do not send them as JSON or base64. Let the browser set multipart boundaries.
- HTTP 202 accepts work. Poll the returned job or the wrapper's job field. Failed jobs are read with HTTP 200 and job.error. Follow result.href only when present.
- List defaults: limit=20, offset=0; request limit is 1–100. Omit optional query filters to disable them; follow next_offset until null.
- Error codes below are proposed contracts. Immediate HTTP errors use ErrorResponse; post-acceptance failures use Job.error. Keep a safe fallback for unknown codes.
- Reviewer IDs are attribution in the local prototype, not authentication credentials.

Common error envelope:

{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "One or more request fields are invalid.",

      {
